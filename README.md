# Morgan Ellison — Consulting CV

Clean personal consulting site for an example advisor profile covering:

- End-to-end HR and people systems
- Management and leadership
- Data analytics and informed decisions
- AI and agentic implementation
- Agile delivery and efficiency
- Challenging the status quo

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8000`.

## Customize

Replace the example name, biography, experience, and `mailto:` address in `index.html` with your details.
